    About PIN Code Buddy

    A dead-simple utility for one job, done fast: turn a 6-digit Indian PIN code into the post office, district, state and delivery status behind it.

    Why it exists

    Most PIN lookup pages bury a simple answer under ads, forms and sign-ups. PIN Code Buddy skips all of it — open the page, type six digits, get your answer. There's nothing to install and nothing to configure.

    Where the data comes from

    Every lookup calls India Post's own public PIN code records in real time via api.postalpincode.in. Nothing is cached on a server or guessed — you're seeing the same data India Post publishes.

    Good to know

    • Works offline for your last few searches once installed — add it to your home screen from your browser's share menu.
    • Your recent searches stay on your device only; nothing is sent anywhere except the PIN code you look up.
    • A single PIN code can cover several post offices (a "cluster") — every branch office and sub office sharing it is listed.
